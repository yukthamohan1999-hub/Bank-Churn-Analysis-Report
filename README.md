# Bank-Churn-Analysis-Report# Bank Churn Analysis Report

## 📌 Project Overview
This Power BI dashboard analyzes customer data to identify key factors driving customer churn (attrition) at the bank. The goal is to provide actionable insights that help the retention team proactively address customer departures.

## 🛠️ Tech Stack & Skills Used
* **Power BI Desktop:** Data modeling, visualization, and dashboard design.
* **Power Query:** Data extraction, transformation, and cleaning (handling null values, changing data types).
* **DAX (Data Analysis Expressions):** Created custom measures for total customers, churned customers, and churn rates.
